# Подбор игры и режима

Подбор — чистая детерминированная функция `matchGames(members, games)`.
API передаёт зафиксированный в комнате каталог; функция не читает БД и не изменяет ответы.

## Сначала ограничения

Пока хотя бы один участник не сохранил пожелания, результат — `pending`.
Пропущенная игра в сохранённом ответе считается недоступной, а не одобренной.
Бесплатность игры не означает, что у человека есть аккаунт, доступ или установка.

Для каждого профиля игры проверяются:

- Доступность и установка у каждого участника.
- Отсутствие «Сегодня не хочу» даже у одного участника.
- Вместимость партии именно в этом режиме, включая явно запрещённые размеры.
- Совместимость режима с каждым жёстким пожеланием: кооператив, соревнование, PvPvE.
- Достаточное время у каждого по редакционному ориентиру выбранного профиля.
- Согласие **всех** на случайных союзников, если команде не хватает игроков.

Размер команды не равен размеру матча. Для компании из двух человек CS может
предложить «Напарников», не требуя ещё троих. ARC Raiders не превращается
в кооператив без угрозы PvP. В VALORANT учтены Swiftplay и Unrated:
запрет партии из четырёх в рейтинге к этим профилям не применяется.

Оценка не отменяет ограничения. Если подходящих профилей нет, игра исключается.
Причины относятся к одному ближайшему профилю с наименьшим числом нарушений;
его название включено в параметры. Это объяснение, а не разрешение нарушить правило.

## Если общих вариантов нет

`emptyDiagnostics` группирует причины по уникальным играм: неподтверждённый доступ, отсутствие установки, запрет участника, время, режим, состав или добор. Группы пересекаются; для личных причин возвращаются ID участников. При `pending` гипотезы не строятся: сначала нужны ответы всех.

Для каждого исключённого профиля функция отдельно собирает допустимые условные изменения: увеличить время до ориентира, выбрать режим, разрешить добор или отметить установку уже доступной игры. На изменённой копии пожеланий повторно проверяются доступ и все ограничения именно этого профиля. Варианты с запретом, неподтверждённым доступом или несовместимым размером компании не выдаются как восстановимые. План перечисляет действия всех участников и не записывает изменения. Установка остаётся условием, которое нужно выполнить в действительности. До трёх планов выбираются детерминированно: меньше участников и полей, меньше добавленного времени, затем ID; для каждой игры остаётся один лучший профиль. Основной допуск и веса ранжирования не меняются.

## Затем ранжирование

Каждый допустимый профиль получает оценку до 100 баллов:

| Сигнал             | Вклад                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------- |
| Желание участников | До 70: «Хочу» = 100, «Не против» = 60, среднее × 0,7                                        |
| Жанр               | До 10: совпадение хотя бы с одним желаемым жанром = 10, несовпадение = 0, без пожелания = 5 |
| Характер вечера    | До 10: совпадение relaxed/focused = 10, несовпадение = 0, любой = 5                         |
| Полнота состава    | До 10: `10 × своих / (своих + случайных союзников)`                                         |

Вклады округляются отдельно и возвращаются как `scoreBreakdown`.
Жанры и характер вечера — мягкие пожелания: они влияют на порядок, но не исключают игру.
Оценка — редакционная мера соответствия, **не вероятность** хорошего вечера.

Из допустимых профилей одной игры выбирается лучший по оценке, затем по меньшему
добору, более короткой сессии и стабильному ID. Между играми первым учитывается
минимальное желание участника: игра, которую хотят все, выше игры с компромиссом.
Затем сравнивается оценка и стабильный ID. Перестановка участников, игр и профилей
не влияет на ответ. Во всех причинах сохраняются ID затронутых участников.

## Примеры

- Двое, 25 минут, можно со случайными: VALORANT → Swiftplay; длинный Unrated не проходит.
- Двое без случайных: CS → «Напарники»; Dota и Overwatch исключены из-за неполной команды.
- Пятеро без случайных: командные профили 5×5 допустимы при остальных условиях.
- Четверо: ARC Raiders исключён по размеру отряда.
- Один хочет только кооператив, другой только соревнование: общего режима нет.

Каталог содержит ориентиры PC-сессий. MMR, роли, уровни аккаунтов, очереди,
региональные ограничения, системные требования и фактическая установка пока не проверяются автоматически.
Длительность включает редакционный запас на сбор, но не гарантирует время завершения матча.
