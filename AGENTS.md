# PartyPick: правила разработки

- Общение и продуктовые тексты — на русском. Код, имена файлов и коммиты — на английском.
- Основной стек: TypeScript strict и React. Frontend следует FSD:
  см. docs/frontend-fsd.md. Сервер — модульный монолит Fastify.
- Перед изменением границ MVP или стека обновлять docs/architecture.md и объяснять причину.
- Визуальное направление — пиксельное игровое лобби: docs/visual-direction.md.
  Не добавлять типовые градиенты, glassmorphism и нечитаемый пиксельный текст.
- Пользователь попросил независимых агентов: для содержательных изменений
  привлекать агента review; для изменений интерфейса — также агента визуального review.
  Дизайн проверять по screenshot desktop/mobile, указывать ограничения проверки.
- Держать тесты соразмерными поведению: matching, права доступа, гонки и
  совместные сценарии важнее тестов, повторяющих разметку.
- Перед завершением: format:check, lint, typecheck, test, build; для UI — test:e2e.
  Не запускать npm ci при работающих dev-серверах на Windows: бинарники могут быть заняты.
- Не хранить секреты и пользовательские данные в Git. Ветки codex/<task>.
- Разделять реализованные возможности, демонстрационные данные и планы.
