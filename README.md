# PartyPick

Сервис для компании друзей: подобрать игру под условия конкретного вечера,
объяснить результат и подтвердить совместный выбор.

## Состояние проекта

Рабочая первая версия для компании из 2–8 друзей:

- Создание приватной комнаты и вход по ссылке без регистрации.
- Сохранение участников и ответов в PostgreSQL/WASM (PGlite).
- Ручной каталог из шести игр: наличие, установка, настроение и доступное время.
- Подбор с объяснениями и причинами исключения игр.
- Голосование, результат, готовность, новый раунд и выход участника.
- Обновление комнаты каждую секунду, обработка конфликтов и сетевых ошибок.

Интерфейс — пиксельное RPG-лобби на React/TypeScript, FSD и Tailwind CSS.
Стили компонентов находятся в JSX. Общие контракты и правила подбора — отдельные
npm workspace-пакеты; сервер — Fastify с параметризованным SQL.

Открытый поиск, RU/EN, импорт Steam и Discord остаются в планах.
Демонстрация на главной подписана отдельно от настоящих комнат.

## Локальный запуск

Требуются Node.js 22.12+ и npm 10+.

```sh
npm ci
npm run dev
```

Интерфейс: http://localhost:5173. API: http://127.0.0.1:3001/api/health.
Vite проксирует `/api` на локальный сервер. Отдельная установка PostgreSQL
локально не нужна: PGlite хранит данные в `apps/api/.data` (не входит в Git).
Используйте один процесс API на каталог данных.
Для API можно задать переменные процесса `PORT` (3001) и `HOST` (127.0.0.1).
При изменении порта API задайте `API_ORIGIN` для Vite.
Для обычного PostgreSQL используйте `DATABASE_URL`; параметры размещения и ограничения
описаны в [API README](apps/api/README.md). Проверки БД пока выполнялись на PGlite,
не на отдельном PostgreSQL-сервере.

Откройте «Создать комнату», отправьте приглашение другу или откройте его
в другом профиле/приватном окне. В одном профиле вкладки разделяют cookie и участника.
Комнаты живут 24 часа. После удаления cookie восстановление гостевого доступа не предусмотрено.
Локальная ссылка localhost доступна только на этом компьютере; совместная игра
между устройствами потребует размещения под единым HTTPS-адресом.

```sh
npm run typecheck
npm test
npm run build
npm run format:check
npm run lint
npx playwright install chromium
npm run test:e2e
```

Сборка интерфейса: `apps/web/dist`. Сборка API: `apps/api/dist`;
запуск собранного API: `npm run start -w @partypick/api`.
E2E запускают отдельные серверы на 5175/3003 с временной БД и не используют
обычный dev-сервер. Порты должны быть свободны. API-тесты проверяют хранение,
сессии, права, гонки, раунды и лимиты; тесты подбора — ограничения и ранжирование.
Сервер API пока не раздаёт собранный интерфейс. Production-размещение — отдельный этап.

## Импорты frontend

`@shares/*` указывает на `apps/web/src/shared/*` в TypeScript, Vite и Vitest:

```ts
import { Button } from '@shares/ui';
import { request } from '@shares/api';
```

## Границы каталога

Каталог описывает поддерживаемые игровые профили без модификаций. Выделенные
серверы и настройки сверх указанных лимитов не учитываются; Pummel Party допускает
ботов для небольшой компании. Длительность — приблизительный ориентир одной
сессии, а не обещание точного времени. Игры должны быть доступны и установлены
у каждого; покупка и установка в текущий вечер не планируются автоматически.
