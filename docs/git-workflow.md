# Git

Исходное состояние: пустой локальный репозиторий, remote не настроен.
Рабочая ветка основания: `codex/partypick-foundation`.

После принятия основания целевая основная ветка — `main`.
Для каждой законченной задачи используем `codex/<short-task-name>` и PR в main.
Отдельная develop-ветка для этого проекта не нужна.

Небольшие коммиты по смыслу: `feat:`, `fix:`, `docs:`, `chore:`, `test:`.
В PR описываем изменение поведения, проверку и известные ограничения.
Перед коммитом: форматирование, типы, релевантные тесты и сборка.
В main изменения попадают после зелёного CI; при подключении GitHub включить
защиту main и обязательную проверку CI. Настройки пока не применены.

Не коммитим `.env`, токены, дампы и node_modules. Lockfile коммитим.
Удалённый репозиторий, видимость и владелец ещё не выбраны;
публикация кода в GitHub пока не выполнялась.
