# Визуальное направление

PartyPick — лобби небольшой инди-игры. Тёплый бумажный фон, тёмные контуры,
оранжевый и шалфейный акценты. Прямые углы, рамка 2px, жёсткая offset-тень 4px.
Пиксельные аватары и небольшие детали; основной русский текст остаётся читаемым.
Без фоновых градиентов, CRT-полос, мигания и бесконечных декоративных анимаций.

Референсы, изученные агентом по содержимому страниц:

- https://itch.io/ — карточки игр, короткие метаданные, акцент на содержимом.
- https://www.lexaloffle.com/pico-8.php — ограниченная палитра и язык картриджей.
- https://lospec.com/palette-list/endesga-16 — согласованная пиксельная палитра.

Это ориентиры, не копирование интерфейса или чужих ресурсов.
Агент не смог получить screenshot референсов; выводы о них основаны на страницах,
а не на полном интерактивном аудите.

Текст минимум 16px, метки не меньше 12px; пользовательские кликабельные зоны
минимум 44px, видимый keyboard focus, состояния обозначаются текстом.
Пиксельный шрифт допустим для короткого лого, но не для длинных абзацев.
Текущий каркас использует системные шрифты без зависимости от Google Fonts.

Демонстрационные данные всегда подписаны. Пока нет сценария создания комнаты,
не показываем притворяющуюся рабочей кнопку. Технический health-индикатор
допустим только в режиме разработки.
